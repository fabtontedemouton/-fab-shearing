# FAB SHEARING — THE REAL LIFE
## Base de production Godot 4.3+

Projet organisé en modules pour construire le simulateur réaliste validé.

### Ouverture
Ouvrir `project.godot` avec Godot 4.3+ et lancer le projet.

### Contrôles clavier
- ZQSD / WASD : déplacement
- Souris : orientation (cliquer dans la fenêtre)
- E ou bouton à l'écran : entrer au poste / action de tonte
- Espace : action de tonte
- Bouton caméra : caméra hybride

### Contrôles Android
- Glisser à gauche de l'écran : déplacement virtuel
- Glisser à droite : orientation caméra
- Bouton d'action : interaction
- Bouton caméra : changer de vue

### Important
Cette base est une architecture et un greybox technique. Elle ne contient pas encore les modèles photoréalistes, les animations riggées, une tonte anatomique, ni le système de carrière complet. Ne pas la présenter comme le jeu final.
