# FAB SHEARING — The Real Life | Pack Godot 1.0

## Transparence sur le livrable
Ce ZIP fournit un projet Godot organisé et une base jouable à enrichir. Ce n'est pas honnêtement un jeu commercial final : les modèles 3D actuels sont provisoires, la tonte est simplifiée et le scoring Bowen n'est pas une évaluation technique certifiée. Un rendu 3D haut de gamme et une formation fiable nécessitent des modèles sculptés/riggés, des textures PBR, des animations, des tests sur téléphone et une validation par un formateur.

## Inclus
- Projet Godot 4, renderer Compatibility pour Android.
- Bergerie/parc 3D, personnage mobile et moutons procéduraux.
- Tonte progressive visuelle simplifiée.
- Carrière locale : argent, XP, niveau, réputation, journées.
- Cinq races de départ : Mérinos, Vendéenne, Suffolk, Texel, Romanov.
- Étapes pédagogiques affichées, à valider avec une référence Bowen qualifiée.
- Sauvegarde locale JSON.
- Charte artistique, exigences de formation, workflow Android.

## Lancer
Ouvrir `project.godot` dans Godot 4.3+ et lancer la scène principale.
Sur PC : WASD si configuré, ou commandes affichées. Sur téléphone : boutons tactiles.

## Export Android
Configurer les templates Godot et le SDK Android, puis utiliser le preset `Android`. Le workflow GitHub Actions produit un APK debug téléchargeable comme artefact.

## Direction artistique non négociable
3D semi-réaliste type grand jeu vidéo. Les moutons doivent être aussi détaillés que les personnages et décors : anatomie, tête, oreilles, yeux, peau, plis, toison en mèches et variations par race. La tonte doit révéler la peau progressivement, zone par zone. Remplacer les primitives provisoires par des modèles sculptés et riggés avant toute commercialisation.

## Formation
La méthode Bowen ne doit pas être inventée. Les séquences, trajectoires et critères doivent être contrôlés par une source pédagogique autorisée et validés par un tondeur/formateur qualifié. Les points de jeu sont pédagogiques et ne représentent pas les notes officielles de concours.
